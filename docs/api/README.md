## 每域文档的固定结构

一份域文档只写这些，**不写机械参数表和响应字段镜像**（那些归 Swagger/`openapi.json`）：

1. **范围与取代的旧对象** —— 对应老系统哪张表/哪些列族，便于回溯。
2. **状态机** —— 枚举全值、允许的跃迁、自动置位点、回退规则、谁可改。
3. **字段语义与口径** —— 只写有争议或易错的：单位、币种、汇率取值日、空值语义。
4. **权限与数据范围** —— 需要哪些权限码、届次/展馆 scope 如何裁剪。
5. **不变量与校验规则** —— 唯一键、跨表一致性、必须服务端原子判断的部分。
6. **待确认疑点** —— 编号引用 `notes/02`（Q 系列）与 `notes/07`（S 系列），**未答复前不得被实现单方面固化**。
7. **验证方式** —— 哪条断言覆盖它（`scripts/dev/smoke-*.mjs` 或 ETL 对账输出）。
